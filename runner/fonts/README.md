# Fonts

`Carlito-Regular.ttf`, `Carlito-Bold.ttf` (metric-compatible with Calibri) and `Lato-RegularItalic.ttf` (used for italics)
are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows redistribution.
Carlito: https://github.com/googlefonts/carlito, Lato: https://www.latofonts.com.
They are embedded as real text in the generated PDFs, so every applicant-tracking parser can read them.
